# 荷语学习模块

入口为 `/delft/?tab=dutch`，与找活动、逛闲置、发闲置、我的并列。沿用现有前端，进入模块时加载，不需要登录或新增服务端接口。

## 内容与维护

- `delft/dutch-content.js`：12 个原创生活场景、36 个练习、独立的 6 题阅读与 KNM 自测，以及官方来源和 A2 科目形式。
- `delft/dutch-store.js`：本机学习进度、复习日期、考试状态及目标日期。日期按 Europe/Amsterdam 计算。
- `delft/dutch.js` / `delft/dutch.css`：页面、作答、自查、语音和录音交互。

IND、DUO 及社会知识来源于 2026-11-13 核对。变更官方要求、出分时间、KNM 内容或考试形式时，先重新验证来源，再更新对应内容和真实核对日期。题目均为本站自编，不能标为 DUO 真题；目前覆盖典型场景，不构成完整考纲。扩充例句时逐项检查荷兰语、答案与解释，保留知识题的可追溯来源。

## 学习记录与媒体

进度、考试状态和最近五次小测结果以版本化结构保存在 `hebao_dutch_v1`，支持损坏数据和禁用存储时继续练习。使用提示、原文或重听的题不计为独立答对。表达题由用户对照示例自查，记录为自评。

听力使用设备提供的荷兰语 SpeechSynthesis 声音。无可用声音时可阅读原文辅助理解，并明确标记为辅助练习。口语录音使用 MediaRecorder，只在当前页面回听，不上传；切换页面、隐藏标签页或离开时停止麦克风。录音与写作正文不持久保存。

自测是固定的六题阅读与 KNM 小测，十分钟倒计时，提交或到时后统一解析。重复练习会遇到相同题目。通过外链进入 DUO 全科官方练习。

## 验证

运行 `npm run check:delft` 和 `npm run test:delft`。浏览器检查导航、完整场景、错误与提示、无荷兰语声音的回退、自查、限时自测、刷新后进度和考试状态，以及 320 / 390 像素手机排版。实际录音还需要浏览器支持和用户授权麦克风。
