# 荷语学习模块

从荷包第二个导航「荷兰语学习」或 `/delft/?tab=dutch` 进入分科备考。切换科目就能查看考试形式、难点和时长，可按题型练习、打开词库，或选择一份未见的限时模拟卷。场景复习和个人考试安排仍可从同一页进入。

## 科目与题库

- `delft/a2-guide.js` 收录五科、15 类本站归纳的练习任务及 104 条按常见考试任务选编的词语和搭配。每条附中文释义及原创荷语例句。词库没有采用考试语料的频次排名。
- DUO 的考试形式与官方样卷于 2026-11-20 核对。阅读 65 分钟、听力 45 分钟、写作 40 分钟、口语 35 分钟、KNM 45 分钟。正式写作是四项纸笔任务。五科共 15 份官方公开练习，从各科直接链接至 DUO 播放器或写作 PDF。变更前从 [官方目录](https://www.inburgeren.nl/examen-doen/oefenen.jsp) 重新核对。
- `a2-objective.js` 和 `a2-output.js` 共 82 项原创任务。每科有六道专项题，每种类型两道。客观科目 A、B 卷各六道。写作、口语各卷四道。维护时保持三组材料独立，并逐项校对答案、解析和知识来源。新听力题需在 `delft/a2-audio/<题目 ID>.mp3` 放入对应的荷语录音。
- `dutch-content.js` 保留 12 个生活场景、36 道练习、原有的六题阅读和 KNM 复习，以及考试安排的来源。原有资料的核对日期为 2026-11-13。

## 测评与记录

专项练习每题即时反馈。原创模拟卷按科计时，到时交卷，提交后统一显示解析。听力使用预制合成录音；专项可看原文，借助原文的答案单列。口语和写作给出参考表达及内容要点，仅记录是否作答。正式整卷请用 DUO 材料，表达质量建议由熟悉 A2 标准的教师复核。

`a2-progress.js` 在 `hebao_a2_prep_v1` 中保存各卷首次打开标记、首次及最近结果、用户录入的官方样卷结果。重做同一份卷不增加独立样本。两份不同的官方样卷都由用户记录为限时独立达标，页面才给出可考虑报考的建议。本站短测仅用于定位练习重点。

`dutch-store.js` 下的 `hebao_dutch_v1` 保留场景进度及考试安排。两份记录都保存在当前浏览器。录音和作答正文只存在当前页面，离开或隐藏学习模块会停止播放与录音。刷新会结束未交卷的作答。

## 验证

运行 `npm run check:delft` 和 `npm run test:delft`。发布前在浏览器检查入口、题型选择、音频播放与原文、写作表格、口语自查、模拟交卷和官方样卷入口。检查窄屏布局。麦克风回听依赖浏览器权限。
