隐私政策（欧盟 GDPR 合规声明）

生效与最近更新日期：2026 年 11 月。荷包（hebaogj.xyz）面向荷兰本地用户提供同城活动组局、二手闲置清单工具及荷兰语 A2 备考服务，严格遵循《欧盟通用数据保护条例》（GDPR）。

1. 我们收集哪些数据及处理目的

  • 邮箱地址：仅用于发送一次性登录验证码（OTP）及与你直接相关的交易咨询、活动报名、改期或取消提醒，绝不向其他用户公开或用于营销群发。
  • 用户主动发布的内容：包括闲置商品名称、照片、价格、公共自取地标，以及同城邀约的时间、公共地点、昵称和报名成员可见的联络说明。
  • 站内沟通与备考进度：买卖双方私信、活动内行前留言，以及登录用户自愿同步的荷兰语 A2 练习与错题记录。
  • 零隐私侵入统计：仅按天汇总页面与核心功能点击次数，不使用第三方广告追踪 Cookie，也不保存明文 IP 地址（防刷限流使用每日轮换的不可逆 SHA-256 摘要）。

2. 数据存储与第三方处理方（Data Processors）

  • 数据库：存储于 Turso（libSQL 云数据库），传输全程 TLS 加密。
  • 公开商品图片：仅在你点击「发布到集市」时上传至腾讯云对象存储（COS）；未发布的草稿照片仅保存在你本机浏览器的 IndexedDB 中。
  • 邮件发送：通过 Resend 发送登录验证码与站内互动提醒。
  • 可选 AI 辅助：仅当你主动点击「AI 补全商品名」或「AI 按 DUO A2 要点批改」时，对应的压缩照片或荷语作答文本才会发送至 Google Gemini API 处理；手动填写与普通刷题不会调用任何 AI 服务。

3. 数据保留周期

  • 邮箱登录验证码：10 分钟内有效，验证成功或过期后立即清除。
  • 闲置清单展示周期：超过 14 天未确认在售的清单自动从公共集市隐藏，卖家可随时一键重新确认或永久删除。
  • 账号与关联数据：在你主动删除单条内容或注销账号前持续保留；注销账号将立即从数据库删除你的账号记录、闲置清单、私信、活动及学习进度。

4. 你的 GDPR 权利与行使方式

你享有知情权、访问与数据可携权（可在「我的 → 账号与个人数据管理」一键导出完整 JSON 数据）、更正权以及被遗忘权（可在「我的」页面一键永久注销账号并清除全部个人数据）。如有隐私相关疑问，可通过页面底部的「问题反馈与建议」与我们联系。

使用条款与线下安全须知

1. 平台定位与免责声明

荷包是面向在荷华人与留学生的免费信息发布、海报生成与学习辅助工具，不介入任何资金代管、支付担保或物流履约。

2. 二手闲置交易准则

  • 优先选择校园、火车站、超市门口等明亮公共场所当面验货交接；切勿在未见到实物前通过 Tikkie、银行转账或微信提前支付「定金」「留货费」或点击陌生快递收款链接。
  • 严禁发布违法违禁品、处方药品、盗版资料或虚假引流内容。

3. 同城邀约与线下安全

  • 发起与参与线下同城邀约须年满 18 周岁，集合地点须为公共场所。
  • 官方「城市活动」信息整理自场馆与市政公开日历，门票及入场规则以主办方官网为准。
  • 发起人如遇天气或个人原因需改期、更换地点或取消活动，应提前在「集合沟通」中更新或点击取消，以便系统邮件通知报名成员。

4. 违规处理与举报

如发现疑似诈骗、骚扰或虚假信息，请立即点击商品、活动或私信卡片上的「举报」按钮。核实违规的内容与账号将被移除。
